# ELITECH Distributor Co., Ltd. — Corporate Website

A modern, premium, responsive corporate website built for **ELITECH Distributor Co., Ltd.**, Cambodia's trusted cybersecurity and enterprise technology distributor.

## Technology Stack
- **Framework**: React.js 18 + Vite
- **Styling**: Tailored Design System with Vanilla CSS Tokens
- **Icons**: Lucide Icons
- **Typography**: Barlow Semi Condensed & Barlow (Google Fonts)
- **Deployment**: Static site optimized for Vercel / Netlify / Cloudflare Pages

## Design System Tokens
- **Primary Brand**: `#00317A` (Deep Cobalt Navy)
- **Accent**: `#F78F20` (Vibrant Safety Orange)
- **Background**: `#FFFFFF`
- **Elevated Background**: `#E9EDF2`
- **Text**: `#010000`
- **Muted Text**: `#6C6B6B`
- **Border Radius**: Buttons (64px), Cards (24px), Images (24px), Containers (32px)

## Local Development

```bash

# 2. Run dev server

# 3. Build for production
npm run build

# 4. Preview production build
```
